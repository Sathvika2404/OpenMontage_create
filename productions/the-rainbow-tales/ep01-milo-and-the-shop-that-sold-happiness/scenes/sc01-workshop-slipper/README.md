
Uploads arrive by attaching images in the chat. Each file is copied into its
`source/` folder **unchanged**, checksummed in `assets_manifest.json`, and
inspected before use. Derived plates and layers are generated by scripts and
never overwrite a source file.

Match the official sheet exactly (face, ears, heart patch, teal bandana with
gold star). Use the same warm window light from frame left as
`workshop_interior_v1`.

**All images:** transparent PNG (not WebP or JPEG), Milo **≥ 1200 px tall**,
facing **right** (the slipper's heel is on its left), no floor shadow, no
